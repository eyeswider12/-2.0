# 视频双语字幕生成器

一款本地运行的 Windows 视频双语字幕工具，支持：

- Whisper 语音识别
- 英译中翻译
- 字幕自动烧录到视频

## 使用方法

1. 下载最新 Release 的压缩包
2. 解压后，翻译2.0\dist\视频双语字幕生成器\视频双语字幕生成器
3. 双击运行 `视频双语字幕生成器.exe`
4.预览选择自己想翻译的MP4格式视频，输出文件夹自动选择
5.点击翻译按钮


## 注意事项

- 首次使用需要准备 Whisper 和 MarianMT 模型
- 推荐使用 `base` 模型（速度与质量平衡）
- 仅支持 Windows

## 开发环境

- Python 3.10
- 依赖见 `requirements.txt`
